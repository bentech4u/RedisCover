1  What are you deploying?

Two very different products. Pick deliberately.

Redis Community (open source)

A single redis-server process as a Deployment + PVC + Service. Free, ~15 MB image, starts in seconds. No clustering, no automatic failover.

Redis via Opstree operator

Open-source operator (community catalog). Four topologies: standalone, replication, Sentinel, cluster. Free, handles failover and bootstrap. Community-supported only.

Redis Enterprise (operator)

A 3-node clustered platform via OLM. Automatic failover, sharding, management UI. Requires a licence, ~1.9 GB image, needs 3 schedulable nodes.
